駐波共振

弦與管的諧音實驗室

互動比較兩端固定、一端固定一端自由、兩端開放的駐波；調整階數、弦長、張力與線密度，視覺化波節波腹、波長、波速及頻率的規律。

開始實驗↗建議將手機轉為橫向操作

觀察重點

  1. 切換兩端固定、一端固定一端自由、兩端開放三種端點條件，比較波節與波腹的位置。
  2. 調整階數 n 與弦長 L，數一數 L 裡容納幾段波長，對照 λ 與 f 的公式。
  3. 改變張力 F 與線密度 μ，以 v=√(F/μ) 比較波速與共振頻率的變化。
  4. 拖動外加驅動頻率掃頻，觀察接近共振頻率時振幅增大並出現穩定的節腹圖樣。
  5. 執行弦長 ×2、張力 ×2 等一鍵實驗，並在下方同條件比較不同階數的圖形。

操作方式

先在上方選端點條件，再用「＋」「−」或滑桿選共振階數 n，調整弦長 L、張力 F、線密度 μ（兩端開放改調空氣溫度 θ）。按「播放動畫」觀察駐波，可改動畫速度或逐格進退。在「外加頻率｜連續掃頻實驗」慢慢拖動驅動頻率；「探索數值規律」可一鍵改參數。

物理模型與限制

理想位移駐波。兩端固定與兩端開放：λ=2L/n、f=nv/(2L)；一端固定一端自由只有奇數諧音：λ=4L/m、f=mv/(4L)，m=2n−1。弦波速 v=√(F/μ)，空氣柱聲速 v≈331+0.6θ（m/s）。開管為空氣質點位移示意，忽略管口端修正與耗散。掃頻採含阻尼的線性受迫振動與固有模態疊加；振幅與播放速度為教學示意。
