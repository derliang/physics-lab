# Physics Lab：設計規範

> 狀態：定案。最後更新：2026-10-25（台北時間）。改任何平台頁面、版面、元件、樣式前先讀這份。要偏離，先更新本文件並取得使用者確認。
> **上架或修訂動畫的對話不需要、也不准修改本文件或平台樣式**；上架只交資料，規則見 [`PUBLISHING.md`](../../PUBLISHING.md)。

- 定案模擬頁：[`mockups/首頁.html`](mockups/首頁.html)、[`mockups/介紹頁.html`](mockups/介紹頁.html)
- 實作位置：`assets/site.css`（全部 tokens 與元件）、`assets/site.js`（畫面產生）、`index.html`、`info.html`
- 範圍：平台頁面（首頁、主題頁、介紹頁）。各動畫的 `index.html` 內部介面不在本文件範圍，依 `ANIMATION_STANDARD.md`。

## 1. 設計原則

1. **明亮科技未來風**：白底與冷灰藍、電光藍到青色的單一強調、細網格與柔和光暈；精緻感來自乾淨的層次與留白，不靠深色背景或花俏特效。
2. **固定版型，資料驅動**：所有畫面由 `simulations.json` 產生。新增動畫不得帶來任何版面變化，否則就是版型設計失敗，要回到本文件修正。
3. **投影優先**：iPad 橫向 1024 是主要畫面，其次桌機、手機；只提供淺色，確保白天教室投影清楚。
4. **不迷路**：任何頁面都看得到目前主題（頁籤或麵包屑），介紹頁一定有回到主題的路。
5. **只呈現真的有的東西**：沒有動畫的主題在頁籤上灰色、不可點，不顯示「籌備中」等字樣，也不做假連結、假數字、假截圖。

## 2. Tokens（定義在 `assets/site.css` 的 `:root`；只有淺色，不提供深色模式）

### 色彩

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f4f7fb` | 頁面底 |
| `--surface` | `#ffffff` | 刊頭、頁籤列、卡片、輸入框 |
| `--ink` | `#0b1526` | 主要文字 |
| `--ink-2` | `#2a3a52` | 次要內文 |
| `--sub` | `#4a5a72` | 說明文字 |
| `--muted` | `#5f6e84` | 關鍵字、支數等輔助資訊 |
| `--disabled` | `#8794a8` | 沒有動畫、不可點的主題 |
| `--rule` / `--rule-soft` | `#dbe3ee` / `#e8eef6` | 分隔線、卡片框 |
| `--field` | `#c7d3e3` | 輸入框與按鈕框線 |
| `--grid` | `#e3eaf4` | 封面背景網格 |
| `--accent` / `--accent-hover` | `#2357ff` / `#163fd6` | 唯一強調色：目前頁、連結、主要按鈕 |
| `--cyan` | `#00b4d8` | 只用於裝飾：漸層收尾、示意圖波谷、光暈；不可用於文字 |
| `--accent-soft` | `#e6edff` | 標籤底色 |
| `--tint-navy` … `--tint-slate` | 見 site.css | 動畫圖示底色（manifest `tint`） |
| `--glow` | 藍色柔光陰影 | 卡片 hover、資訊欄、示意圖 |

- 漸層只用在三處：刊頭 3px 色條、區段標題下的短線、封面大標的強調字。不做大面積漸層背景。
- 圖示色票（只給 icon.svg 用）見 `PUBLISHING.md` 第 4 節，與介面 tokens 分開管理。

### 字型

| 用途 | token | 字型 | 字級／字重 |
|---|---|---|---|
| 介面與內文、中文標題 | `--font-body` | Noto Sans TC | 內文 16px／1.6；封面 34～58px（clamp）／700；區段 30px／700；卡片 18px／700 |
| 刊名、品牌 | `--font-tech` | Space Grotesk | 刊名 22px／700 |
| 編號、標籤、支數、FIG. | `--font-mono` | JetBrains Mono | 11～15px |

- 由 Google Fonts 載入；載入前或失敗時退回系統字型，版面不得因此跑掉。

### 間距、圓角、動態

- `--gutter: clamp(16px, 4vw, 40px)`；內容最大寬 `--maxw: 1160px`。
- 圓角：卡片 `--radius-card` 14px；控制項 `--radius-control` 10px；搜尋框、主要按鈕、手機主題按鈕 `--radius-pill`。
- 動態：卡片 hover 框線變 `--accent`、加 `--glow`、上移 3px；`prefers-reduced-motion` 時取消。刊頭固定在畫面頂端（sticky）並半透明模糊。

## 4. 元件規則

- **刊頭**：3px 藍青漸層色條＋品牌標記＋刊名（Space Grotesk）＋中文站名＋搜尋＋關於本站。搜尋框 44px 高；<600 時收成 44×44 放大鏡按鈕（`aria-expanded`）。
- **主題頁籤**：「全部」加七個物理主題，順序固定（力學、熱學、波動、電磁學、光學、近代物理、實驗與數據）。
  - 有動畫：原生連結，下方顯示「N 支」；目前項目 `aria-current="page"`、藍色底線（<720 為實心藍膠囊）。
  - 沒有動畫：`<span aria-disabled="true">` 只顯示主題名稱、`--disabled` 灰字、不可點、不顯示任何狀態文字。
  - 每個可點項目點擊區至少 44px 高。網址 `index.html#<category>` 可直接分享；指到沒有動畫的主題時顯示「全部」。
- **主要按鈕 `.btn`**：`--accent` 實心膠囊、48px 高（介紹頁 52px）、藍色柔光陰影。一個畫面只放一顆。
- **動畫卡片 `.card`**：整張卡是原生 `<a>`，連到介紹頁。內容順序固定：圖示圖版 → 標題 → 副標（有才顯示）→ 簡介（最多 3 行，手機 2 行）→ 前 3 個關鍵字 → 「閱讀介紹 →」。不顯示狀態徽章。
- **圖示圖版 `.plate`**：`data-tint` 決定底色，內放動畫的 `icon.svg`（`<img>`，裝飾用 `alt=""`）。
- **區段標題 `.section-head`**：「編號（mono）＋主題名＋說明」，右側動畫數，下方 1px 分隔線加 72px 漸層短線。
- **狀態訊息 `.notice`**：載入中、目錄錯誤、搜尋無結果、找不到動畫，各有不同文字，不能混用。
- **麵包屑**：首頁 › 主題 › 動畫名；每段連結至少 44px 高。
- **介紹頁資訊欄**：圖示（有截圖時）→ 開始實驗 → 主題／建議裝置／更新日期 → 關鍵字標籤 → 同主題動畫（最多 3 支）→ 回到主題。

## 5. 頁面規則

### 首頁 `index.html`（模擬頁 `mockups/首頁.html`）
- 預設（全部）：刊頭 → 頁籤 → 封面（網格與光暈背景、大標、導言、主要按鈕、開放數、雙波源干涉示意圖）→ 每個有動畫的主題一個區段。沒有動畫的主題不出現區段。
- 選定主題（`#waves`）：隱藏封面，只顯示該主題區段。
- 搜尋：隱藏封面，跨主題顯示「搜尋結果」區段；從介紹頁搜尋會帶 `?q=` 回首頁。
- 頁尾保留既有版權句（見 `AGENTS.md` 版權維護規範），不得刪改。

### 介紹頁 `info.html?sim=<category>/<slug>`（模擬頁 `mockups/介紹頁.html`）
- 刊頭 → 麵包屑 → 主欄：主題標、標題、副標、導言、截圖（`cover.webp`，沒有則放大圖示）、觀察重點（01、02… 編號清單）、操作方式與物理模型（並排，手機上下）→ 資訊欄。
- 「開始實驗」連到動畫原網址 `simulations/<category>/<slug>/`，同頁開啟。
- 已下架或不存在的動畫顯示「找不到這支動畫」，不顯示任何內容。

## 6. 文案語氣

- 台灣繁體中文，平實、精準；不用驚嘆號、emoji、行銷語（「超神奇」「一鍵搞定」）。
- 按鈕用動詞：「開始實驗」「閱讀介紹」「瀏覽全部動畫」。
- 平台固定文案寫在 `assets/site.js` 與 HTML；動畫文字全部來自 manifest。

## 7. 無障礙

文字對比至少 4.5:1（上列文字 tokens 在 `--bg` 與 `--surface` 上皆符合；`--disabled` 僅用於不可操作項目）；點擊區至少 44×44px；整卡用原生連結，可 Tab、Enter、開新分頁；焦點外框 3px `--accent`；圖示為裝飾，標題文字永遠存在。

## 8. 不要做的事

- 不為單一動畫客製首頁或介紹頁（特殊顏色、特殊區塊、置頂、徽章）。
- 不在平台頁面寫死任何動畫的名稱、圖示或連結。
- 不做深色模式或深色背景；不加大面積漸層背景、霓虹發光文字、emoji 圖示、左側色邊卡片。
- 不新增第二個強調色；`--cyan` 只做裝飾。不新增分類。
- 不顯示「籌備中」「即將推出」等未上架主題的狀態文字。
- 不在動畫頁面插入平台的導覽或版權橫幅（動畫頁只有檔頭註解，見 `ANIMATION_STANDARD.md` 第十二章）。
