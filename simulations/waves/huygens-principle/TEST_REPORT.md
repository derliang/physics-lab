# 惠更斯原理 V2.4｜圓形波第一代與反射波前修正

測試日期：2026-10-21（臺灣時間）

## 修改內容
- 圓形波第一代從**單一圓心點波源**開始，半徑 `r = v₁·t` 隨播放時間增長；第一代的子波外緣就是新波前，不重複疊畫。第二、三代才由上一代圓周取樣建立子波、包絡線；保留三代循環。
- 反射：將入射與反射波前改為**有限長、同一切向長度 300 畫面格**的週期性平面波前，反射波前由「已跨過介面」的入射波前部分對介面做鏡射，兩種波前的內在長度與平行方向不隨代數改變。畫面邊界及介面處會裁切尚未進入或正在形成的部分，此為物理上正常的顯示限制。
- 反射：波源接觸時間取決於波前在介面上的實際到達位置及波峰／波谷期別；尚未接觸時不畫出黃色子波或點波源。
- 其他模式、控制項、首頁及目錄產生器皆未更動。

## 自動化驗收（Chromium/Playwright）
- 在 1366×900、1024×768：反射模式 t=2T 尚無實際可見反射線段，關閉或開啟子波／波源畫面完全一致；t=4T 有新形成反射線，開關子波／波源後畫面有正確差異。
- 反射前進到第 15 代與第 46 代仍有反射波前，沒有固定代數截斷；檢驗所繪入射、反射幾何線段的原始長度均為 300 格。
- 入射角 0°、60° 的波前原始長度仍為 300 格。
- 圓形波第一代分別在 1/8、1/2、7/8 週期觀察到半徑 9.375、37.5、65.625 格的唯一擴張波前；第二、第三代與循環按鈕運作正常（承襲前置驗收）。
- 圓形波、直線波前、折射、障礙物繞射、雙縫干涉共五種模式對 V2.4 修改前候選版的 canvas 圖像**逐像素一致**。
- 本次新增程式通過 Node JavaScript 語法檢查。兩種視窗下均無 Javascript pageerror。

## 已知限制
- 當有限長波前正在碰撞反射面或部分移出可見畫面時，畫面上可見片段會比完整波前短；不應因此把可見片段誤解為原始波前長度縮小。
- 此反射視覺化採幾何平面波模型，沒有模擬反射面上的能量損失與有限波束邊緣繞射。
- 尚未在 iPad Safari 實機及教室投影裝置執行驗收，未測試所有極端參數組合。
